        Set up the Like shortcut

        The Like shortcut sends a URL from the share sheet straight to your site, without opening WriteNow. A Note shortcut works the same way for dictation or the Action Button.

        These steps name the Shortcuts actions as they appear in current iOS. They have not been checked on a device, so the names may differ slightly.

        1. Create a password for Shortcuts

        Shortcuts get their own Application Password, named “WriteNow Shortcut”, so you can revoke it separately.

        Shown once. Copy it into the shortcut now. If you lose it, create another and revoke the old one in your profile.

        2. Build the Like shortcut

        1. In Shortcuts, create a shortcut named “Like”. In its details (ⓘ), turn on Show in Share Sheet. Set it to receive only URLs and Safari web pages, and set “If there’s no input” to Get Clipboard.
        2. Add Get URLs from Input with the Shortcut Input.
        3. Add Get Item from List set to First Item, because the site expects one URL.
        4. Add Get Contents of URL with this URL:
          Under Show More, set Method to POST. Add the header Authorization with the value from step 1. Set Request Body to JSON with one text field, url, set to the Item from List. Leave out the title; the site looks it up.
        5. Add Get Dictionary Value for the key message in the Contents of URL.
        6. Add Show Notification with the Dictionary Value.

        Share a page to Like: it should say “Liked: …”, and “Already liked: …” the second time. With no connection, Shortcuts shows an error and nothing is sent; there is no outbox.

        3. Optional: a Note shortcut

        Two variants: one saves a draft, one publishes. The draft one is recommended for dictation, so you can fix it in Recent before it goes out.

        1. Create a shortcut named “Note”. Add Dictate Text (or Ask for Input to type).
        2. Add Get Contents of URL with this URL:
          Method POST, the same Authorization header, and a JSON body with two text fields: content set to the Dictated Text, and status set to draft (or publish to post right away).
        3. Add Get Dictionary Value for message, then Show Notification.
        4. To use the Action Button: Settings → Action Button → Shortcut → Note.

        The full recipe, with commands to check the endpoints from a laptop, is in docs/writenow/shortcuts.md in the site’s repository.
